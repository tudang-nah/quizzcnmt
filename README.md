# Thử thách Năng lượng gió

Trò chơi trắc nghiệm 5 câu về năng lượng gió (Nhóm 05). Web tĩnh thuần HTML/CSS/JS, không cần build.

## Cấu trúc
- `index.html` – toàn bộ game
- `favicon.svg` – icon tab
- `vercel.json` – cấu hình Vercel (tùy chọn)

## Chạy thử local
Mở `index.html` bằng trình duyệt, hoặc `npx serve .`

## Deploy lên Vercel
1. Push repo lên GitHub.
2. Vào vercel.com → Add New → Project → Import repo.
3. Framework Preset: **Other**. Để trống Build Command và Output Directory.
4. Bấm Deploy.
